# 古時計 — 公開サポートサイト

iPhoneアプリ「古時計」の利用者向け公式サポートページとプライバシーポリシーを公開するためのリポジトリです。

- [サポート・お問い合わせ](https://hideyaza.github.io/furudokei-pages/support.html)
- [プライバシーポリシー](https://hideyaza.github.io/furudokei-pages/privacy.html)

問い合わせ先：nannkayattemiyou@gmail.com

このリポジトリには一般公開用のWebページのみを置きます。iOSアプリ本体のソースコードは別の非公開リポジトリで管理されています。

## GitHub Pagesの設定

リポジトリの **Settings → Pages** で「Deploy from a branch」を選び、ブランチ **main** と **/(root)** を設定して Save してください。公開後は上の2ページへログインせずアクセスできることを確認してください。

Webページを更新するときは、このリポジトリ直下の `index.html`、`support.html`、`privacy.html` を編集します。アプリ本体の `public/` 以下の旧コピーだけを変更してもこの公開サイトには自動反映されません。
